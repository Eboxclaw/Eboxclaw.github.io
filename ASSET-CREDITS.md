# Asset credits

## Profile knight

The low-poly knight model was assembled with [Grab3D Character Mixer](https://grab3d.com/tools/character-mixer/) and exported with its idle and wave clips. The creator states that exported characters are released under CC0 1.0, with no attribution required. The model is included locally as `assets/profile-knight.glb`; `assets/profile-knight-poster.png` is its static loading fallback.

## Web component

The 3D model is displayed with [Google model-viewer](https://modelviewer.dev/), version 4.4.0, loaded from Google's CDN. The project is licensed under Apache 2.0.
