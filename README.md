# Cristiano Vilas Boas, profile site

A static profile page that presents the CV as a website. The original CV PDF is intentionally not included or linked.

## GitHub Pages

The intended repository is [Eboxclaw/Eboxclaw.github.io](https://github.com/Eboxclaw/Eboxclaw.github.io), which publishes at [https://eboxclaw.github.io/](https://eboxclaw.github.io/).

To publish this folder, put its contents at the repository root, then select **Settings → Pages → Deploy from a branch → main → /(root)**.

## Files

- `index.html` is the complete page.
- `assets/` contains project artwork and the animated profile character.
- `assets/profile-knight.glb` is the CC0 character model with idle and wave animations.

The page uses Google’s `<model-viewer>` web component, pinned to version 4.4.0, from the Google-hosted CDN. See `ASSET-CREDITS.md` for asset details.
